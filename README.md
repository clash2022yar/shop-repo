# دیجینو | Digino

فروشگاه راست‌چین کالای دیجیتال با **Laravel 13.21.1**، Blade، HTML، CSS،
**Tailwind CSS 3.4** و JavaScript استاندارد + Fetch/AJAX.
هیچ React، Vue، Alpine، Livewire، Vite، jQuery یا فریم‌ورک فرانت‌اندی در پروژه استفاده نشده است.
طراحی و توسعه: **یارمحمدی**.

## وضعیت نسخه و محیط

- هدف استقرار: **PHP 8.3.28**؛ Dockerfile به همین نسخه دقیق متصل است.
- محدودیت محیط Arena: دانلود مستقیم PHP/Packagist در این جلسه خطای شبکه داشت.
  پیش‌نمایش و تست‌ها با **PHP 8.3.8** و SQLite 3.40.1 اجرا شده‌اند، نه 8.3.28.
- Composer 2.8.10 و تمام وابستگی‌های `composer.lock` (شامل وابستگی‌های توسعه) نصب شدند.
  به‌دلیل محدودیت Packagist، متادیتای بسته‌ها از مراجع GitHub خوانده و توسط خود Composer
  حل و نصب شد. هیچ کد vendor دست‌کاری نشده است. مخزن موقت حل وابستگی وارد پروژه نشده؛
  نصب معمول از lock و URLهای رسمی GitHub امکان‌پذیر است.
- سازگاری PHP در Composer برای 8.3.28 حل شده؛ Symfony 7.4 سازگار با PHP 8.3 انتخاب شده است.
- Docker در این محیط موجود نبود؛ ساخت Dockerfile هنوز در Docker اجرا و تأیید نشده است.

## اجرای محلی

پیش‌نیاز: PHP 8.3.28، Composer 2، SQLite 3.26+ یا MySQL 8 و افزونه‌های
`ctype`, `curl`, `dom`, `fileinfo`, `filter`, `hash`, `intl`, `mbstring`, `openssl`,
`pdo`, `pdo_sqlite` (یا `pdo_mysql`), `session`, `tokenizer`, `xml`, `zip`.

```bash
cp .env.example .env
composer install
php artisan key:generate
touch database/database.sqlite
php artisan migrate
# اختیاری: ۹۰ محصول نمونه، ۱۰ دسته‌بندی، ۲ بنر و ۳ مقاله
php artisan db:seed
php artisan shop:admin
php artisan serve --host=0.0.0.0 --port=8000
```

`shop:admin` نام، ایمیل و رمز مدیر را تعاملی دریافت می‌کند. رمز در کد، مخزن یا README
وجود ندارد. ثبت‌نام عمومی هیچ‌گاه دسترسی مدیر ایجاد نمی‌کند.

CSS کامپایل‌شده داخل مخزن است؛ برای نمایش سایت Node لازم نیست. برای تغییر Tailwind:

```bash
npm ci
npm run build
```

در Arena با PHP بسته‌بندی‌شده، برای پرهیز از حذف متغیرهای کتابخانه توسط زیرپردازش Artisan:

```bash
cd public
php -S 0.0.0.0:8000 -t . ../vendor/laravel/framework/src/Illuminate/Foundation/resources/server.php
```

این سرور فقط برای توسعه و پیش‌نمایش است، نه سرویس عمومی تولید.

## اجرای نسخهٔ دقیق با Docker

```bash
cp .env.example .env
docker compose build
docker compose run --rm app composer install
docker compose run --rm app php artisan key:generate
touch database/database.sqlite
docker compose run --rm app php artisan migrate --force
docker compose run --rm app php artisan db:seed  # فقط برای نمونه
docker compose run --rm app php artisan shop:admin
docker compose run --rm --user root app sh -c 'chown -R www-data:www-data storage bootstrap/cache database public/uploads'
docker compose up -d
```

سایت روی پورت `8080` باز می‌شود. برای محیط تولید باید HTTPS، پشتیبان‌گیری،
مالکیت فایل‌ها، محافظت شبکهٔ FPM و دامنهٔ واقعی تنظیم شوند. فایل `.env`:

```dotenv
APP_ENV=production
APP_DEBUG=false
APP_URL=https://your-real-domain.example
SHOP_DEMO=false
SESSION_SECURE_COOKIE=true
```

پروکسی فعلی برای پیش‌نمایش مورد اعتماد است؛ در سرور عمومی `trustProxies` را به
IP پروکسی‌های واقعی محدود کنید. فقط `public/` باید DocumentRoot باشد.
`storage`، دیتابیس و `public/uploads` باید قابل نوشتن برای کاربر PHP باشند.
برای داده واقعی `db:seed` اجرا نکنید؛ دسته‌ها و محصولات را از پنل مدیر بسازید.

## صفحات و عملیات

### فروشگاه
- خانه، فهرست محصولات، دسته‌ها، صفحه دسته، نتایج جستجو و پیشنهاد جستجوی زنده
- فیلتر برند/دسته/قیمت/موجودی/تخفیف، مرتب‌سازی و صفحه‌بندی AJAX
- جزئیات، بزرگ‌نمایی تصویر، مشخصات و دیدگاه با تأیید مدیر
- سبد خرید واقعی مبتنی بر نشست، تغییر تعداد، حذف و کد تخفیف
- ثبت سفارش، آدرس تحویل و **پرداخت هنگام تحویل**
- ورود/ثبت‌نام با ایمیل و رمز، خروج و تغییر رمز
- حساب کاربری، سفارش‌ها، جزئیات و لغو پیش از ارسال
- علاقه‌مندی، بازدید اخیر، آدرس‌ها، ویرایش پروفایل و تیکت پشتیبانی
- مجله و مقاله، درباره، شرایط حقوقی، حریم خصوصی، پرسش‌ها و راهنماها
- عضویت خبرنامه: ثبت واقعی ایمیل؛ ارسال انبوه ایمیل پیاده‌سازی نشده است.

### مدیریت (`/admin`، فقط برای مدیر)
- آمار محاسبه‌شده از دیتابیس و نمودار سفارش‌های ۷ روز اخیر
- افزودن/ویرایش/بایگانی محصول، بارگذاری تصویر و مشخصات JSON
- CRUD دسته‌بندی، کوپن، بنر و مقاله
- سفارش‌ها و تغییر وضعیت مجاز، مشتریان (مشاهده)، موجودی
- بررسی و تأیید/حذف دیدگاه، پاسخ تیکت، فهرست/حذف اعضای خبرنامه
- تنظیمات نام، تماس، آدرس، هزینه ارسال و حد ارسال رایگان
- عملیات CRUD از مودال‌ها یا فرم‌های AJAX بدون بازخوانی کامل صفحه انجام می‌شود.

### اجزای مشترک

```
resources/views/layouts/     app, admin
resources/views/partials/    header, footer, icon, product-card, pagination,
                            account-sidebar, admin-sidebar, order-summary,
                            cart-content, address-modal, order-detail
resources/views/store/       صفحات فروشگاه
resources/views/account/     ورود و حساب کاربری
resources/views/admin/       مدیریت
app/Http/Controllers/        کنترلرهای تفکیک‌شده
app/Http/Middleware/         مجوز مدیر و هدرهای امنیتی
app/Services/                منطق سبد و سفارش
app/Models/                  مدل‌ها با Fillable attributes لاراول
config/admin.php             فهرست مجاز منابع، فیلدها و قواعد اعتبارسنجی
```

هدر، فوتر و سایدبارها تنها یک منبع دارند. صفحات ورود، ثبت‌نام، حساب و مدیریت **فوتر ندارند**.
تاریخ‌ها با تقویم فارسی Intl و ساعت تهران نمایش داده می‌شوند. ورودی تاریخ مدیریت ISO است.

## دادهٔ نمونه

Seeder تکرارپذیر است و ۱۵ مدل پایه + بسته‌های مشخص ۲ تا ۶ عددی می‌سازد؛ در مجموع ۹۰ محصول.
عنوان و قیمت بسته‌ها صریح است؛ بسته چندعددی به عنوان مدل متفاوت دستگاه معرفی نمی‌شود.
قیمت و موجودی آزمایشی‌اند و باید پیش از فروش واقعی جایگزین شوند.
سفارش، امتیاز، آمار فروش یا مشتری ساختگی در Seeder وجود ندارد.
با `SHOP_DEMO=true`، کد `DIGINO10` برای آزمایش ساخته می‌شود. مدیر نمونه تنها در صورت
تعیین صریح `DEMO_ADMIN_PASSWORD` ساخته می‌شود. این تنظیم را در تولید فعال نکنید.

## امنیت و یکپارچگی سفارش

- احراز هویت نشست، هش رمز، تجدید شناسه نشست پس از ورود و خروج امن
- حفاظت پیش‌فرض `PreventRequestForgery` لاراول ۱۳ حفظ شده؛ معافیت CSRF وجود ندارد.
- محدودسازی نرخ ورود، ثبت‌نام، خبرنامه، دیدگاه و سفارش
- مجوز نقش مدیر و کنترل مالکیت سفارش/آدرس
- فهرست مجاز منابع و فیلدهای مدیریت، جلوگیری از تزریق نقش در ثبت‌نام
- مبلغ صحیح تومان، محاسبه قیمت در سرور، بررسی موجودی و کوپن
- تراکنش دیتابیس و قفل رکورد، قفل نشست برای تغییر سبد/ثبت سفارش
- توکن یکتای checkout برای جلوگیری از ثبت دوباره؛ بازگشت موجودی فقط یک‌بار هنگام لغو
- ثبت snapshot نام، تصویر، قیمت و آدرس سفارش؛ تغییر محصول یا آدرس، سفارش قبلی را عوض نمی‌کند.
- اعتبارسنجی تصویر، نام تصادفی فایل، نپذیرفتن SVG آپلودی یا URL خارجی
- CSP، nosniff و هدرهای حریم خصوصی؛ خروجی متنی Blade escape می‌شود.
- کش صفحات خصوصی غیرفعال است؛ محدودسازی iframe اعمال نشده تا پیش‌نمایش Arena کار کند.

## محدودیت‌های صریح پیش از راه‌اندازی تجاری

- درگاه بانکی، پیامک OTP، ارسال واقعی ایمیل و اتصال شرکت حمل‌ونقل پیاده‌سازی نشده‌اند.
  دکمه یا تراکنش شبیه‌سازی‌شده برای آن‌ها وجود ندارد.
- ورود با ایمیل/رمز است؛ بازیابی خودکار رمز یا تأیید ایمیل در این نسخه ارائه نشده است.
- امکان دانلود اپ، پرداخت اقساطی و نشان اعتماد جعلی قرار داده نشده است.
- مدیریت مشتریان فقط مشاهده است؛ تغییر نقش مدیر عمداً از UI عمومی حذف شده است.
- بازگشت کالا از طریق تیکت پیگیری می‌شود؛ گردش مالی استرداد وجه مستقل وجود ندارد.
- مالکیت و مجوز تصاویر باید بررسی شود: `docs/ASSETS.md`.
- لایسنس حقوقی جلوی کپی فنی مخزن عمومی را نمی‌گیرد؛ برای محدودکردن دسترسی کد، مخزن را خصوصی نگه دارید.

## آزمون‌ها

```bash
php vendor/bin/phpunit
php artisan view:cache
composer validate --no-check-publish
npm run build
```

آزمون‌های Feature شامل صفحات، احراز هویت، نقش، CRUD، سبد، کوپن، مالکیت،
کمبود موجودی، ثبت تکراری، لغو سفارش، دیدگاه و تیکت هستند.
همچنین مسیر ثبت‌نام → سبد → آدرس AJAX → ثبت سفارش، فیلتر، علاقه‌مندی،
ویرایش آدرس و مودال CRUD مدیریت در Chromium بررسی شده است.
فایل‌ها و داده‌های موقت تست مرورگر داخل Git قرار ندارند.
