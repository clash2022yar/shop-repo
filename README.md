# دیجی‌نو | DigiNo

فروشگاه اینترنتی کالای دیجیتال — یک پروژهٔ کامل **Laravel 13 / PHP 8.3** با رابط کاربری راست‌به‌چپ فارسی،
ساخته‌شده با **Tailwind CSS (Tailwind CLI)** و **JavaScript خالص** (بدون Vite، بدون React/Vue/Alpine).

طراحی: **یارمحمدی**

---

## فهرست امکانات

**فروشگاه**

- صفحهٔ اصلی با اسلایدر، بنرهای تبلیغاتی، پیشنهاد شگفت‌انگیز (با شمارش معکوس)، پرفروش‌ترین‌ها، جدیدترین‌ها و مجله
- فهرست کالاها، دسته‌بندی، برند و جستجو با فیلترهای زنده (AJAX)، مرتب‌سازی و صفحه‌بندی بدون رفرش
- صفحهٔ کالا: گالری، انتخاب تنوع (رنگ/حافظه)، مشخصات، دیدگاه‌ها، پرسش و پاسخ، کالاهای مرتبط
- مقایسهٔ کالا، علاقه‌مندی‌ها، بازدیدهای اخیر
- سبد خرید، کد تخفیف، تسویه‌حساب چندمرحله‌ای، پرداخت و رسید سفارش
- مجله (وبلاگ)، صفحات ثابت، تماس با ما، پرسش‌های متداول، قوانین و حریم خصوصی

**حساب کاربری**

داشبورد، سفارش‌ها، جزئیات سفارش، فاکتور چاپی، آدرس‌ها، علاقه‌مندی‌ها، دیدگاه‌ها، پرداخت‌ها،
اعلان‌ها، تیکت‌های پشتیبانی، پروفایل و امنیت حساب.

**پنل مدیریت**

داشبورد و نمودارها، کالاها (افزودن/ویرایش با تنوع، تصاویر و مشخصات)، دسته‌بندی‌ها، برندها،
سفارش‌ها و تغییر وضعیت، مشتریان، کوپن‌ها، دیدگاه‌ها، پرسش‌ها، انبار و گردش موجودی، بنرها،
مطالب مجله، صفحات ثابت، تیکت‌ها، روش‌های ارسال، کاربران پنل، گزارش‌ها و تنظیمات.

## نصب و اجرا (Laravel)

```bash
composer install
cp .env.example .env
php artisan key:generate

touch database/digino.sqlite
php artisan migrate --seed        # داده‌های آزمایشی فراوان

npm install
npm run build                     # ساخت public/css/app.css با Tailwind CLI

php artisan serve
```

حساب‌های آزمایشی پس از Seed:

| نقش | ایمیل | گذرواژه |
| --- | --- | --- |
| مدیر کل | `admin@digino.test` | `password` |
| مدیر فروش | `manager@digino.test` | `password` |
| مشتری | `user@digino.test` | `password` |

## پیش‌نمایش ایستا (بدون PHP)

اگر PHP در دسترس نباشد، همان فایل‌های Blade با یک موتور کوچک Blade در Node رندر می‌شوند تا
طراحی قابل بررسی باشد:

```bash
node preview/build.js      # ساخت صفحات در preview/dist
npm run preview            # اجرای سرور روی http://0.0.0.0:3000
```

صفحهٔ `/pages.html` نقشهٔ همهٔ صفحات ساخته‌شده را نشان می‌دهد.
داده‌های این پیش‌نمایش معادل Seederهای پروژه است و رفتارهای پویا (AJAX، مودال، فیلتر) فقط در
نسخهٔ واقعی Laravel اجرا می‌شوند.

## ساختار پوشه‌ها

```
app/            کنترلرها، مدل‌ها، Enum‌ها، سرویس‌ها، میدل‌ورها، Policyها و هلپرها
bootstrap/      پیکربندی برنامه به سبک Laravel 11+ (bootstrap/app.php)
config/         تنظیمات، از جمله config/digino.php
database/       مهاجرت‌ها، Factoryها، Seederها و دادهٔ کاتالوگ
public/         css و js کامپایل‌شده، تصاویر، فونت‌ها
resources/      قالب‌های Blade و ورودی Tailwind
routes/         web.php، admin.php، ajax.php، console.php
preview/        موتور پیش‌نمایش ایستا (فقط برای بازبینی طراحی)
```
