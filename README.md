# دیجینو - Digino Shop

فروشگاه اینترنتی **دیجینو** با الهام از دیجی‌کالا، ساخته شده با **PHP 8.3.28** و **Laravel 13** و طراحی اختصاصی با **Tailwind CSS** و **Vanilla JS + AJAX**.

> سازنده: **یارمحمدی**  
> کلیه حقوق این سایت متعلق به دیجینو می‌باشد.

## ویژگی‌ها
- صفحه اصلی، فروشگاه، دسته‌بندی، جستجو، جزئیات محصول، سبد خرید، تسویه حساب
- احراز هویت (ورود/ثبت‌نام) با AJAX بدون رفرش
- داشبورد کاربری: سفارش‌ها، جزئیات سفارش، علاقه‌مندی‌ها، آدرس‌ها، تیکت
- پنل ادمین کامل: داشبورد، محصولات، افزودن/ویرایش، دسته‌بندی، سفارش‌ها، مشتریان، کوپن، نظرات، موجودی، بنرها، تنظیمات
- هدر/فوتر/سایدبار قابل Include
- بدون Vite/React/Alpine - فقط HTML+Tailwind+JS+AJAX+Laravel
- انیمیشن‌های فراوان، SVG به جای استیکر، Tailwind CDN
- دیتای فیک زیاد (40+ محصول، دسته، برند، سفارش)

## نصب
```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

## لایسنس
این پروژه **اختصاصی و غیرقابل کپی** است. هرگونه کپی‌برداری بدون اجازه کتبی سازنده پیگرد قانونی دارد. متن کامل در صفحه درباره ما.
